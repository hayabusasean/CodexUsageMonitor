# 2026-10-26 程式碼與新手說明檢查

這是作者維護流程中的針對性檢查，不是獨立第三方資安稽核。

## 已重現並修正

`HistoryStore.Append` 原本只排除已存在於檔案的識別值，沒有排除同一批輸入內重複的識別值。新增兩項測試，在修改產品前都失敗；修正後重新檢查單批重複與重新開啟後的重複寫入。修正使用 `DistinctBy(id)`，不更改歷史欄位，不清洗既有檔案。

發行包原本把含相對圖片／文件連結的網頁 README 複製成 README.txt，離線閱讀缺乏可用的操作入口。新版改打包專用中文文字說明，使用完整網址；發行審查器的預設報告版本改為讀取當前專案版本，避免一直指向 beta2。

## 安全邊界抽查

檢查了額度請求白名單、API Key 帳號拒絕、官方程式簽章與子程序、公開網站來源及轉址限制、本機資料與匯出、一般使用者權限，以及正式版排除測試入口的設定。新增測試再次確認模型任務、購買提示、兌換、登入寫入等請求不在允許清單。

沒有把未發現外傳程式碼說成「絕對不可能外傳」，也沒有把程式自行限制的請求當成作業系統沙盒。官方 Codex 的行為與發布 EXE 的安全仍需分開評估。

本次重新編譯並執行 **13 組、398 項自動檢查：397 通過、1 項略過、0 失敗**。略過的項目是測試磁碟沒有提供 8.3 短檔名；沒有為了測試改動磁碟設定。
