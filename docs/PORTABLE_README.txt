CodexUsageMonitor 0.5.0-beta3 — Codex 額度小幫手

這是免費、非官方的 Windows 64 位元測試工具。不是 OpenAI 的產品。

第一次使用
1. 先確認同一 Windows 帳號已安裝支援的官方 Codex，並用 ChatGPT 帳號登入。
   只有瀏覽器登入不夠；只有 API Key 的登入方式不適用。
2. 把下載的 ZIP「解壓縮全部」，保留整個資料夾。
3. 檢查來源及電腦的安全提示，再決定是否開啟 CodexUsageMonitor.exe。
   不必另裝開發工具或 .NET Runtime，不需要管理員權限。
4. 取得資料後會顯示額度，預設約 90 秒更新一次。

怎麼操作
大數字是每週剩餘額度。浮窗按右鍵，可看使用紀錄、額度詳情、重置消息與設定。
視窗不見時，點右下角通知圖示；圖示可能藏在 ∧ 裡。
要停止記錄，選右鍵選單的「離開」，不是只隱藏視窗。
紅點只是公開消息提醒，不保證帳號會重置。關機或工具沒開時不會補造紀錄。

費用與隱私
本工具不收費、不要求 API Key，不送出模型生成任務，不購買點數或兌換券。
官方 Codex 本身與你另外使用的 AI，仍依各自服務規則計費。
設定和歷史留在本機，不自動傳給作者。公開消息會連網，網站能看見一般網路資訊。
本工具尚未加發布者數位簽章；不要關閉防毒，也不要上傳登入檔或完整私人資料。

升級
先從舊版選「離開」，保留資料備份，再開新版。
歷史預設存在 %LOCALAPPDATA%\CodexUsageMonitor。
不要直接退回 0.4.1；設定保護方式不同，請先閱讀線上升級教學。
