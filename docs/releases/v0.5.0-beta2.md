## 這次更新

- 標準／精簡浮窗顯示每週剩餘、燒速與重置倒數；標準模式也顯示照目前速度何時用完、重置券數與最早到期時間。下次查詢秒數移到 tooltip。
- 每週重置與公告重置各自計算預測，主倒數採較早者。燒速以跳格時間與完整可觀測視窗計算，至少需要兩個不同跳格、累積 2 個百分點，才提供估計。
- 通知區單擊叫回浮窗，右鍵第一項依狀態顯示「顯示浮窗／隱藏浮窗」，專屬圖示顯示剩餘百分比。
- Radar 支援 RSS category、同作者 30 分鐘內的回覆合併、X status ID 原始時間、可設定詞庫及洛杉磯／台灣時間。即將重置的來源每 5 分鐘檢查；長期 403 來源標示「被網站封鎖」並移出可讀率分母。
- 重置時間比對容忍正負 120 秒，新增尚未開始的週期、提前重置與缺口期間重置判讀。`ACCOUNT_STABLE`／`EMAIL_SCOPED` 讓同範圍紀錄可比較；原始 email 不落地。
- 新增五類重置／券提醒，同一條件 6 小時內最多一次；`status.v1.json` 提供不含帳號識別資料的狀態，供其他本機工具讀取。
- JSON 內容未變就不重寫；來源檢查與覆蓋率採每日 JSONL，採樣使用七日記憶體快取。背景預先合成並快取；正式程式不包含測試入口。
- beta2 加入正式的獨立資料目錄、實際 EXE／寫入量診斷、首次 Paint 診斷及開機捷徑隔離防護。Salt 以原 Windows 帳戶的 DPAPI 保護，保持原身分鍵。

## 升級與退版

1. 從舊版右鍵選單選「結束」，確認舊程序停止。
2. 備份 `%LOCALAPPDATA%\CodexUsageMonitor`，至少另存升級前的 `settings.json` 與 `history`。
3. 下載 `CodexUsageMonitor-v0.5.0-beta2-win-x64.zip`，解壓縮整個資料夾，啟動 `CodexUsageMonitor.exe`。不需另裝 .NET Runtime。
4. 使用原 Windows 帳戶及原資料目錄，即可接續設定與歷史；再次開啟同資料目錄的程式只會叫回既有程序。

**退回 0.4.1 前，必須先結束新版並還原升級前含舊 Salt 的 `settings.json`。** 0.4.1 不認得 `SaltProtected`，直接讀新版設定可能產生新身分鍵。保留最新 `history`，不要用舊備份覆蓋新增紀錄；沒有舊設定備份時先不要直接啟動 0.4.1。

工具維持唯讀，只呼叫 `initialize`、`account/read`、`account/rateLimits/read`、`account/usage/read`。不送模型回合、不兌換券、不直接讀 `auth.json`，也不保存 email 或 token。CSV 的 schema 1、欄位順序、只追加、ID 去重與尾端修復保持相容。
