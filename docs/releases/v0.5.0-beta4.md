# CodexUsageMonitor 0.5.0-beta4

2026-10-26 · Windows x64 · 測試版

## 這版改了什麼

首頁改成先下載、再操作、再看安全與費用。新增新手教學、可以直接貼給 AI 的三種指引，以及能在解壓縮資料夾直接閱讀的中文 README.txt。保留原有實機圖片和進階查核資料。

修正同一批資料重複出現時，可能把相同觀察寫進歷史檔多次的問題。這次只防止新增重複，不回頭刪除或重寫既有歷史。

把「匯出分析 Log」「複製診斷摘要」「額度池」等常見用語改得更容易懂。資料欄位、歷史格式、設定保護方式及唯讀額度查詢限制維持不變。

另外修正開機捷徑在不同 Windows 語系下，遇到中文或其他非英文路徑可能保存失敗的問題。改用 Windows 的 Unicode 捷徑介面，並保留原本的失敗測試，再加上中文資料夾、檔名、目標路徑與失敗時保留資料的檢查。

**beta3 已發布的檔案與標籤保留不動；需要本次捷徑修正請用 beta4。**

## 檢查範圍

本次重新編譯並執行 **13 組、401 項自動檢查：400 通過、1 項略過、0 失敗**。略過的項目是測試磁碟沒有提供 8.3 短檔名；未修改磁碟設定。

原本在 GitHub Windows 測試機失敗的中文捷徑案例保留不變，另外新增中文資料夾／目標路徑的內容核對、重複建立與移除、保存失敗時保護原資料等測試。本次本機四項捷徑檢查都通過；GitHub 雲端檢查另以實際 Actions 結果為準，不拿本機結果代替。

另外在不切換使用者桌面的隔離環境，執行 100%／150% 顯示縮放測試，各 43 項，共 **86 項通過**。這是合成資料與靜態視窗擷取，不是正式帳號的長時間驗收或開窗錄影。

額度請求仍限於四種初始化／帳號／額度讀取操作，不加入購買、兌換或模型任務。沒有替換使用者正在執行的程式，也沒有修改私人歷史。
