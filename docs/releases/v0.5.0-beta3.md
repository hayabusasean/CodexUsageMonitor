# CodexUsageMonitor 0.5.0-beta3

2026-10-26 · Windows x64 · 測試版

## 這版改了什麼

首頁改成先下載、再操作、再看安全與費用。新增新手教學、可以直接貼給 AI 的三種指引，以及能在解壓縮資料夾直接閱讀的中文 README.txt。保留原有實機圖片和進階查核資料。

修正同一批資料重複出現時，可能把相同觀察寫進歷史檔多次的問題。這次只防止新增重複，不回頭刪除或重寫既有歷史。

把「匯出分析 Log」「複製診斷摘要」「額度池」等常見用語改得更容易懂。資料欄位、歷史格式、設定保護方式及唯讀額度查詢限制維持不變。

## 檢查範圍

本次重新編譯並執行 **13 組、398 項自動檢查：397 通過、1 項略過、0 失敗**。略過的項目是測試磁碟沒有提供 8.3 短檔名；沒有為了測試改動磁碟設定。

另外在不切換使用者桌面的隔離環境，以 100%／150% 顯示縮放執行合成畫面測試，**各 43 項，共 86 項通過**。產生靜態畫面並抽看使用紀錄與設定頁；不是正式帳號的長時間驗收，也不是視窗首次出現過程的錄影。

重複寫入的兩項測試在修正前失敗、修正後通過；另外兩項查核確認 API Key 帳號拒絕與不允許模型／購買／兌換／登入寫入請求。本次沒有用真實登入重跑正式監控，也沒有替換使用者正在執行的工具或私人歷史。

[機器可讀的測試與校驗摘要](verification-beta3.json)記錄本次數字及範圍；原始碼庫內的測試可供重新檢查。

檢查不等於安全認證。尚未證明所有 Windows 版本、螢幕縮放、通知權限或長時間運作都正常。公開消息可能延遲；官方 Codex 的登入及網路行為另由它自己處理。
