# 第一次使用：不用懂程式，也能看懂

[回首頁](../README.md) · [讓 AI 帶你操作](AI_HELP.md) · [費用與安全](../PRIVACY.md)

## 先確認你適不適合使用

這份程式給 **Windows 64 位元（x64）** 電腦使用。主要實測環境為 Windows 11；未保證所有 Windows 版本、ARM 電腦或螢幕配置都可用。Mac、Linux 不能直接執行這份 EXE。

你還需要在同一個 Windows 使用者帳戶下，安裝支援的**官方 Codex** 並用 ChatGPT 帳號登入。只有在瀏覽器登入 ChatGPT，不代表電腦已安裝 Codex。只有 API Key 的登入方式不適用這個工具。

尚未安裝官方程式，可先看 [OpenAI 官方使用入口](https://chatgpt.com/codex/)與[官方安裝說明](https://learn.chatgpt.com/docs/quickstart)。官方的名稱、安裝位置與介面可能改版；是否能被本工具找到，仍須實際檢查。**不要為了這個監測工具先買新方案或點數。**

不清楚自己是哪種電腦？可以請自己的 AI 先協助確認，或在 Windows「設定 → 系統 → 關於 → 系統類型」查看；不要先執行陌生指令。

## 第一步：下載對的檔案

[直接下載 v0.5.0-beta4 的 Windows 壓縮檔](https://github.com/hayabusasean/CodexUsageMonitor/releases/download/v0.5.0-beta4/CodexUsageMonitor-v0.5.0-beta4-win-x64.zip)

檔名應是 **`CodexUsageMonitor-v0.5.0-beta4-win-x64.zip`**。也可以打開[本版下載頁](https://github.com/hayabusasean/CodexUsageMonitor/releases/tag/v0.5.0-beta4)，找到 `Assets`（下載檔案），選同名 ZIP。一般下載公開檔案不必建立 GitHub 帳號。

`Source code (zip)`、`Source code (tar.gz)`、綠色 `Code → Download ZIP` 都是原始碼。除非你打算自行編譯，否則不要選它們。

本版仍是測試版，所以 GitHub 的 `Latest` 可能指向舊正式版。**認上面的版本號和完整檔名，不要只認 Latest。**

## 第二步：解壓縮，不要在 ZIP 裡直接開

在下載好的 ZIP 上按右鍵 →「解壓縮全部」→ 選一個自己的普通資料夾。打開解壓縮後的資料夾，裡面應有 `CodexUsageMonitor.exe`、`README.txt` 和授權說明等檔案。

把整個資料夾保留下來，不必放進 Windows 系統資料夾。工具不需要額外安裝 .NET、Visual Studio、Python，也不需要系統管理員權限。

## 第三步：先判斷安全提示，再決定開啟

這是個人發布、**尚未加上發布者數位簽章**的程式，Windows 可能表示不認識發布者。這不等於一定有病毒，也不等於一定安全。

請先確認下載來源是本專案的 GitHub 下載頁。可以先用 Windows 安全性掃描；有明確的惡意程式警告、公司政策禁止或來源不明時，就先停止。**不要關閉防毒、加整個資料夾到排除清單，或以管理員權限硬開。**

下載頁的 `SHA256SUMS.txt` 是檔案校驗清單。它用來確認拿到的檔案是否與發布檔一致，不是安全保證。需要核對時可請有電腦操作能力的 AI 協助，要求先說明做法且不要先執行程式。不能操作電腦的 AI 也不能憑網址核對你手上的檔案。

## 第四步：啟動，確認能讀到額度

確認官方 Codex 已登入後，雙擊 `CodexUsageMonitor.exe`。正常連線後會出現額度數字；預設約 90 秒查一次，失敗時會隔一段時間自動重試。

工具**不會要求你貼 API Key、密碼、驗證碼、登入檔或瀏覽器 Cookie**。需要登入時，請在官方 Codex 自己的登入流程操作，不要把登入資料傳給作者或 AI。

剛裝好沒有歷史曲線、速度顯示資料不足，通常是還沒累積足夠觀察。工具不會回頭讀取你的對話，也不會補造安裝前的歷史。

## 每天怎麼用

大百分比是這週「剩餘」多少。在浮窗上按右鍵，可開啟「使用紀錄」「額度詳情」「重置消息」「設定」「關於」。把滑鼠移到資訊上，有些地方會顯示補充說明。

「使用紀錄」可選今天、7 天或日期範圍。曲線中斷代表沒有觀察資料，不代表當時一定沒用。額度回到 100% 代表觀察到補滿，原因仍可能未知。

「重置消息」會看部分公開網站。紅點或公告倒數只是在提醒，**不要因此假定每個帳號都能重置或急著花點數**。需要確認購買、點數或券，請自行查看官方頁面。

「匯出表格」產生 CSV（可用試算表軟體開啟）；「匯出分析報告」產生詳細文字報告，舊版按鈕稱「匯出分析 Log」。它們只存到你的電腦，沒有自動上傳。分享給 AI 前要先檢查時間紀錄、備註與個人資訊。

## 視窗不見了怎麼辦

點 Windows 右下角時鐘附近的工具圖示；圖示可能藏在 `∧` 裡。也可以在圖示按右鍵選「顯示浮窗」。再次開啟相同資料目錄的程式，通常會叫回已開啟的那一份，而不是多開。

要停止監測，用右鍵選單的 **「離開」**。隱藏浮窗不等於停止記錄。

## 遇到問題先看這裡

| 情況 | 先做什麼 |
| --- | --- |
| 找不到 Codex | 確認同一 Windows 帳戶已安裝官方程式，先開官方程式確認可用，再到本工具「設定 → 檢查連線」。不要先改系統設定。 |
| 要求登入／沒有每週額度 | 先在官方 Codex 查看登入與帳號狀態。帳號或官方版本沒提供資料時，本工具不能自己算出額度。 |
| 一直顯示正在連線 | 查看設定頁的連線訊息；網路或官方服務問題會自動重試。不要刪登入檔，也不要貼金鑰。 |
| Windows 或防毒阻擋 | 停止，先核對來源並看安全警告。不要關防護。 |
| 圖片顯示不完整、字太小 | 提供 Windows 顯示縮放比例及遮掉私人資訊的截圖；不必先改系統縮放。 |
| 下載後只有 src、tests 等資料夾 | 你拿到原始碼了。回第一步下載檔名包含 `win-x64.zip` 的試用包。 |
| 手機上下載了檔案 | 這份程式需要 Windows 電腦，不能直接在手機執行。 |
| 想請 AI 幫忙 | 複製 [AI 指引](AI_HELP.md) 的排查段落，不要先丟整包私人紀錄。 |

回報問題時，提供程式版本、Windows 版本、你按了什麼、畫面訊息即可。從「關於 → 複製問題摘要」可先預覽摘要，再按一次複製；舊版稱「複製診斷摘要」。它比完整歷史報告更適合一般排錯，但分享前仍應看一眼。

## 升級與退版

**從 beta2／beta3 升到 beta4：** 先在舊版選「離開」，保留舊版資料夾與資料備份，再解壓縮新版到另一個資料夾並啟動。資料仍在 `%LOCALAPPDATA%\CodexUsageMonitor`；不要用舊備份覆蓋新紀錄。這次不更改歷史表格格式，也不自動清洗既有重複資料。

**從 0.4.1 升級：** 在舊版已離開、尚未第一次開新版時，先備份本工具的資料夾，尤其 `settings.json` 與 `history`。可在檔案總管網址列貼上 `%LOCALAPPDATA%\CodexUsageMonitor` 找到它。備份只留在自己電腦，不上傳。

**退回 0.4.1 要特別小心：** 新版的設定保護方式不同。必須先離開新版，再還原「第一次升級前」的 `settings.json`，並保留最新的 `history`。不要拿 `pre-bilingual.bak` 當成一定可用的退版備份。沒有正確備份就先不要退版；讓 AI 看[進階說明](ADVANCED.md)與[舊版升級紀錄](releases/v0.5.0-beta2.md)。

## 不用了怎麼移除

先在設定取消開機啟動並儲存，再選「離開」，最後刪除你解壓縮的程式資料夾。設定與歷史預設保留在本機；只想停用，不必刪它們。

要連歷史一起刪除，先備份並確認目標是 **CodexUsageMonitor 自己的資料夾**，再自行處理。不要刪官方 Codex 的 `.codex`、登入檔或開發專案。
